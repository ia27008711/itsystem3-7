# AGENTS.md — 編集ルール

## 最優先
- 既存のゲーム進行、画面デザイン、演出、操作を、依頼なく削除・簡略化しない。
- 変更前に関連ファイルと参照パスを確認する。
- 不明な過去仕様や未収録ファイルを推測で作らない。
- 変更は小さく段階的に行い、既存機能を保つ。

## 構成・パス
- `CSS` と `JavaScript` の大文字表記は既存HTMLの参照と一致しているため、変更する場合は参照箇所をすべて同時に更新する。
- 相対パスを維持し、GitHub Pages / Netlify などの静的ホスティングで動作する構成にする。
- ライブラリを追加する前に、既存機能や標準APIで代替できないか確認する。
- 空のフォルダや未使用ファイルを、用途を確認せずに追加・削除しない。

## JavaScript
- `game.js` を分割する場合は、グローバル参照、初期化順、イベント登録、アニメーションループ、状態共有を先に調査する。
- 既存の関数名・DOM ID・CSSクラスを不用意に変更しない。
- 毎フレーム処理に不要なオブジェクト生成や重い探索を追加しない。
- タイマーやイベントリスナーを追加する場合は、重複登録や終了後の残留に注意する。

## テスト・報告
- 実行していないテストを「確認済み」と書かない。
- 変更したファイル、維持した機能、未確認事項を最後に列挙する。
- HTML/CSS/JSの構文確認だけで、実際のゲームプレイ確認を代替したと主張しない。
